# College Placement Management System

A web-based College Placement Management System built using Flask, Python, HTML, CSS, and MySQL.

## Features

### Student
- Student registration
- Student login
- Student dashboard
- View available jobs
- Search jobs
- Check job eligibility
- Apply for jobs
- Track application status
- Logout

### Company
- Company registration
- Company login
- Company dashboard
- Post jobs
- View posted jobs
- Edit jobs
- Delete jobs
- View applicants
- Update applicant status
- Logout

### Admin
- Admin login
- Admin dashboard
- View students
- View companies
- View jobs
- View applications
- View placement statistics
- Logout

## Technologies Used

- Python
- Flask
- MySQL
- HTML5
- CSS3
- Jinja2
- Werkzeug
